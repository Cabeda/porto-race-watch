About this map

Porto Marathon · 8 November 2026, 08:00 Lisbon time.

Chip timing confirms a runner crossing a checkpoint. Between checkpoints, the orange dot estimates progress using the speed from the latest read. It is an estimate, not live GPS.

Estimates stop at the next checkpoint until another read arrives. An overdue read returns the dot to the last confirmed checkpoint. Green numbered dots show provisional race leaders.

Runner timing refreshes every minute during the race, every five minutes beforehand. Leaders refresh every two minutes. Hidden tabs pause updates.

Search by registered name or bib and select an entry. Bibs become searchable when the organiser publishes them. Identical names need a bib to confirm identity.
