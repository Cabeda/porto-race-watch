A LITTLE CONTEXT

A dot with an honest label.

This page reads the public TRACX timing feed for Porto Marathon 2026. A chip read confirms the runner crossed a particular checkpoint.

Between reads, we estimate progress along the official course using the speed recorded at the latest checkpoint. This is an estimate, not live GPS. It cannot detect a stop, a pace change or a missed timing mat.

The estimate stops at the next checkpoint until a new read arrives. If the next read is overdue, the dot returns to the last confirmed checkpoint and is labelled stale. Rankings are provisional.

Updates run every minute during the race, every five minutes before it, and pause while the page is hidden. Leaders refresh every two minutes. No account or runner phone is needed for chip timing.
